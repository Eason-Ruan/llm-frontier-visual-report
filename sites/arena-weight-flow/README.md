## 界面语言

- 默认显示英文，右上角 EN / 中文按钮切换完整界面；包括 Dashboard、Storyboard、29 个子榜及分组、说明、提示、表格、无障碍标签、画布与悬浮取值线。

## D3 绘图与报告集成构建

当前图表使用 D3 的独立模块，已移除未使用的 Recharts 依赖：

- `d3-scale` 负责月份带宽、序位、分区及前沿差距的坐标变换；`d3-array` 按原始名次组织并列组。
- `d3-shape` 负责实际人数归一化的堆叠、每月阶梯面积与缺失断段的前沿路径，直接绘入 Canvas。
- `d3-interpolate` 与 `d3-timer` 负责模型方块和分区形变，保留原有 1450ms、逐模型延迟、落定弧线和减少动态效果。
- 原有峰值、百分比避让、斜线、悬浮命中优先级、月份明细与 SVG 取值线保持同一份几何／数据。绿色表示开权重，砖红表示闭权重，灰色表示未知；许可细分时 Apache/MIT 与其他开权重使用深浅绿。

在本目录运行 `npm run build:report`，会以 Vite `report` 模式构建到 `dist-report/`，然后由 `scripts/install-report.mjs` 安装到 `../../dashboards/ch1/`。报告模式固定英文与 Dashboard，隐藏侧栏、语言切换和独立站页首，并引用报告服务提供的返回入口 `/static/bridge.js`。独立站 `npm run build` 仍保留 Storyboard、侧栏和中英切换；报告模式不覆盖独立站的浏览器偏好。

`dashboards/ch1/BUILD_INFO.json` 记录来源、构建命令与打包资源校验值。请修改本目录源码后重新运行构建命令，不要直接编辑报告中的压缩 JS。数据 JSON 没有重算。

## 图表与口径

- 29 个 Arena Text 子榜，各月最后一个可用快照；Top 10/50 按原始 `rank <= N` 选择。
- 排名方块：第一名在上，按榜单顺序连续拼接完整色块；并列模型各占一个正常单元，同组用灰色边框标注。纵轴显示序位，原始名次见提示与明细；边界并列完整延展，早期未满席位留空。
- 面积组成：同一组模型按 Apache/MIT、其他开放许可、闭权重、未知归类，使用实际模型数归一化。
- 每个模型以同一方块进行位置和尺寸插值，带向下落定弧线；不是两个图表淡入淡出。
- 支持减少动态效果、键盘切换、月份明细表、画布悬浮提示及窄屏横向滚动。
- 开放权重不等同于 OSI 开源 AI；原始许可标签不自动证明历史法律状态。早期榜单覆盖有限。

## 分区与颜色开关

- 整体堆叠：整个 Top N 样本为一个占比区域。
- 三区堆叠：第 1–10 / 11–30 / 31–50 名，区间无重复；分区高度按 10 / 20 / 20 个名次比例分配。
- Top 10 下隐藏堆叠方式选择器，固定使用整体堆叠；返回 Top 50 恢复原选择。分区使用模型原始排名，边界并列完整归入该排名所属区间。
- 每区按本月该区实际模型数独立归一化；没有模型的区间不填充。分区占比不能直接当作整体模型占比。
- 默认 Apache/MIT 与其他开权重模型同为浅绿；开启“Apache / MIT 显示深绿”后区分。开关同步作用于排名、堆叠、图例、提示和明细色标，不改变数据或分类。
- 切换堆叠方式自动进入面积视图；面积分区之间保留模型身份进行位置插值。

## 完整时间轴与 Cutting edge gap

所有子榜统一展示 2023-05 至目录中最后月份。灰色斜线是没有快照，不是 0；不对缺失月份前向填充或连线。2023-12 为前沿比较起点。

早期标注采用“本数据集闭源覆盖不完整”，不能写成闭源未参评：LMSYS 2023-05-10 公告已列出 GPT-4 / Claude / GPT-3.5，来源 https://www.lmsys.org/blog/2023-05-10-leaderboard/ 。该标注不改写原始历史排名。

前沿生成器读取每月完整快照，以各权重组最小原始 rank 为最强名次；同名次模型全部留档。Top10 色块仍只保留 rank≤10 的模型，但前沿不会被 Top10 截断；必要时扩展纵轴并标出 Top10 边界。

差值为 open.rank - closed.rank：正值闭权重领先，负值开权重领先，0 表示原始排名并列。一组缺失时差值为空。差距视图淡化原始色块，将闭权重前沿移至零线，将开权重前沿移为有符号差值；这是排序差，不是评分差、能力差或统计显著性。

## Gap 斜线与内联峰值标注

前沿之间用彩色斜线标记 gap，与无数据月份的灰色反向斜线区分。尖峰定义为正 gap 的局部最大值或负 gap 的局部最小值；连续等值峰顶作为一个事件，缺失月份不参与两侧比较。最新月的单侧极值单独标为待确认（*）。

峰值数值直接标在两条线之间，模型短名称标在上下两端。无常驻卡片、编号或下方标签区；鼠标悬浮 gap 数字时出现小卡片，保留日期、完整模型标识、原始名次、峰顶平台内模型更替及并列最强模型。短名仅用于显示，不改变实体标识；+N 提示同峰顶另有模型。

## 面积组成的峰谷与百分比参考线

- 适用于主 Dashboard 的 Top10 / Top50、整体／三区堆叠，以及 Storyboard 的两种 Top50 堆叠。
- 整体图画稍浅的灰色（#737b80）25%、50%、75% 参考线及数字；全部采用 5px / 4px 虚线，50% 线宽 2.6px，其余 2px。三区每区只保留较细的 1.6px 50% 参考线和数字，使用各区独立尺度；关闭静态峰谷竖线及其百分比，不显示静态选中月份竖线。悬浮取值线仍保留。
- 先提取开、闭权重占比的局部峰谷，连续同值段合并，无快照或空分区打断比较。同月互补峰谷共用一条竖线，百分比在各自颜色区域中间；0% 位于边界，未知值不归入闭权重。
- 整体堆叠的峰谷标注按滚动六个月窗口筛选：最多一个峰和一个谷，同类标注的月份差至少为 6；不是固定的上／下半年分箱。方向以开权重为基准，只有闭权重发生转折时反向归类，避免互补的同一个事件占两个名额。
- 优先保留转折幅度更大的事件：确认峰谷用该值相对左右相邻观测的较小差值，末端事件用单侧差值；同幅度优先更极端的值，再优先已确认事件，最后以较早月份打破平局。比较容差为 1e-10，避免浮点误差改变平局结果。末端未确认事件也受六个月限制，保留星号。只筛选标注，不平滑或改变原始面积数据；gap 规则不变。
- 面积图悬浮不弹模型／峰谷卡片。`AreaRuler.jsx` 在当前月份画一条取值线，显示各区两个纯百分比，不加“开／闭”前缀；颜色与图例标识权重状态，辅助阅读标签仍保留含义。存在未知权重时另记未知，无快照或空分区显示“无数据”，不补零。悬浮暂时收起静态峰谷标注，移开恢复；点击固定实际鼠标所在月份。Storyboard 两图的取值线同步。
- 悬浮取值线和整体堆叠峰谷线在红绿交界处增加两个小箭头：红色朝向上方闭权重区域，绿色朝向下方开权重区域；零高度区域不画指向该区域的箭头。极薄区域会缩小箭头，避免越过分区边界。
- Apache/MIT 深绿开关不改变开权重合计。百分比保留最多一位小数，单独四舍五入后显示之和可能有 0.1 个百分点的误差。排名／gap 视图保留原有模型与前沿提示。
- `node tests/composition.mjs` 检查 29 子榜三个组合（Top10整体、Top50整体、Top50三区），1,262 个原始候选筛选后保留 721 个（算法检验数，三区页面已关闭静态标注）；校验滚动窗口、相隔六个月的边界、跨年、同幅度规则、同值平台、缺失、未知、零值与末端状态。
